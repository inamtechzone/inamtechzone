Backup

Download a full JSON export of Products, Categories, Brands, Orders, Settings, Admins (without password hashes), Coupons, Reviews, and the Activity Log. Since the database is Google Sheets itself, you can also always restore from Sheets' own built-in version history (File → Version history) at any time.

Maintenance

If any product images stopped previewing, they were likely saved with an older, less reliable Drive URL format. This rewrites every product's images to the current, more reliable format — safe to run any time, and does nothing to products that are already fine.
